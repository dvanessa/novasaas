# Security Policy

## Supported versions

NovaSaaS Free 1.x is currently supported for security reports.

## Reporting a vulnerability

Do not report suspected vulnerabilities through public issues or discussions.
If GitHub private vulnerability reporting is enabled for this repository, use
that feature to submit a report. Otherwise, contact the repository owner
privately through their GitHub profile:
https://github.com/dvanessa

Please include enough detail to reproduce the issue, and avoid sharing
unnecessary personal or sensitive data. Production dependencies can be checked
with `npm run audit:production`.
