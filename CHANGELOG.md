# Changelog

All notable changes to NovaSaaS Free are documented in this file.

## 1.0.0 — 2026-10-02

### Added

- Responsive SaaS dashboard with metrics, revenue visualization, subscription
  distribution, and recent activity
- Product landing page and live demo entry points
- Responsive dashboard shell with collapsible sidebar and mobile navigation
- Light, dark, and system themes
- Command menu, notifications, organization switcher, and user menu
- Demo authentication, account recovery, registration, and email verification
- Typed roles, permissions, route guards, and permission-aware navigation
- Reusable component library and design system showcase
- Open Graph metadata, generated product icon, and robots metadata
- Vitest and React Testing Library coverage
- Netlify deployment configuration
- MIT license

### Documentation

- Added installation, customization, security, deployment, and demo-account
  guidance
- Documented the boundary between NovaSaaS Free and the planned Pro edition
